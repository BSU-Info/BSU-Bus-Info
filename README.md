# 🚌 BSU Bus Info

Welcome to **BSU Bus Info**!

BSU Bus Info is a **fan-made** website dedicated to **Bus Simulator: Ultimate**. Our goal is to provide accurate and helpful information for players in one place.

## Features

- 🚌 Bus database
- 💰 Bus prices
- ⚡ Bus top speeds
- 👥 Passenger capacities
- 📖 Guides and tips
- 📰 Latest updates
- ⭐ Rankings and comparisons
